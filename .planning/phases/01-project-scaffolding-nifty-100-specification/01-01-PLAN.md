## Threat Model (ASVS Level 1)

| Threat ID | Category | Component | Description | Mitigation |
|-----------|----------|-----------|-------------|------------|
| T-01-01 | Input Validation | `Candle` | Corrupted / manipulated candle data (e.g. inverted prices, negative volume, NaN values) causing division by zero or silent algorithm failure | Strict Pydantic model validator checking `high >= max(open, close)`, `low <= min(open, close)`, `volume >= 0`, `price > 0`, and non-NaN values |
| T-01-02 | Integrity | `UniverseConfig` | Incomplete or manipulated universe config (e.g. duplicate symbols, unmapped sectors, altered trading hours) leading to missing surveillance coverage | Pydantic validator enforcing exactly 100 unique NSE symbols, valid benchmark references, and immutable config objects |
| T-01-03 | Tampering | Domain Entities | Accidental in-place mutation of candle or feature states across replay pipelines causing lookahead data leakage | Models declared with `frozen=True` and `extra="forbid"`, preventing runtime attribute modification |
</threat_model>
